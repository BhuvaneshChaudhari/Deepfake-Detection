Frequently Asked Questions

How accurate is DeepGuard's detection?

DeepGuard currently achieves an accuracy of approximately 92-95% on our test datasets. However, accuracy may vary depending on the quality of the input and the sophistication of the deepfake.

What file formats are supported?

For images: JPG, PNG, JPEG. For audio: WAV, MP3. Files should be under 5MB for optimal performance.

How can I improve detection results?

Use clear, high-quality files. For images, ensure faces are clearly visible. For audio, use recordings with minimal background noise.

Is my data stored when I use DeepGuard?

No, we do not store your uploaded files. All processing is done in memory and files are discarded after analysis.
